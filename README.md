# 纪慧个人简历 · 网页应用

保留原有米白纸感、咖啡棕配色和画册式作品展示。包含封面照片、左侧目录、六组作品、项目分组、大图查看、个人资料及联系方式。

iPhone 请用 Safari 打开网站，等待“离线内容已就绪”，再通过“分享 → 添加到主屏幕”添加桌面图标。首次加载需要联网；浏览器清理缓存后需要再次联网。关闭制作方电脑不会影响托管网站访问。

这是可安装到桌面的网页应用，不是 App Store 安装包。静态文件可迁移至其他 HTTPS 托管平台。所有资源均使用相对路径，支持子目录发布。

不含原始 PDF、原生工程、签名文件或账号凭据，不提供原文档下载功能。字体许可见 OFL-NotoSerifSC.txt。网站包含经用户授权展示的个人资料及作品。
